**Arya Chahankar** works the front line of a Security Operations Center — the layer between
noise and incident. Days are spent inside SIEM dashboards, packet captures, and access
logs, separating the anomaly from the artifact.

Trained as a Computer Science engineer with a specialization in Cyber Security, the path
started in offensive testing — breaking web apps, APIs, and mobile clients apart to see
how they fail — before moving to the defensive side, where that same instinct is used to
catch failures before they become breaches.

The interest isn't a single discipline. It's the full loop: **detect → investigate →
respond → harden.**
